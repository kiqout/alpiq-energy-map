# Alpiq Energy Atlas

An independent interactive atlas that turns Alpiq's publicly reported electricity-production and climate data into an explorable visual experience.

The project combines a Three.js globe, a dedicated 3D Switzerland terrain scene, production breakdowns, and comparisons that put energy figures into everyday context.

> **Disclaimer:** This is an independent project and is not an official Alpiq product. It is an educational data visualization, not a tool for tracking electricity deliveries or the physical flow of power.

## Explore the atlas

- **World and Europe:** rotate and zoom an interactive 3D Earth with a satellite-style nighttime-lights texture.
- **Switzerland:** switch to a separate 3D terrain view with orthophoto, shaded relief, and annual VIIRS nighttime-radiance data. Toggle between Satellite and Night lights.
- **Production overview:** explore reported generation by year, country, and technology, with installed capacity shown where a verified figure is available.
- **Lighting-demand comparison:** view generation as either a percentage of estimated building and outdoor-lighting demand for the same reporting period, or as equivalent days at the region's normal lighting load.
- **Climate context:** explore equity-share Scope 1 and 2 emissions data and clearly labelled illustrative comparisons.
- **Five languages:** English, German, French, Italian, and Romansh. The selected language is saved in the browser.
- **Responsive interface:** layouts adapt to desktop and mobile screens; reduced-motion preferences are respected.

## Run locally

### Requirements

- Node.js 20 or newer (Node.js 22 is configured for Netlify)
- npm

### Install and start

```bash
npm ci
npm run dev
```

Open the local address printed in the terminal. The development server normally uses `http://localhost:5173`.

### Available commands

```bash
npm run build       # Create the production site in dist/
npm run typecheck   # Run the TypeScript check
npm test            # Run calculation and data-consistency tests
npm run media:download  # Download the photo assets used by the cards
```

The `dist/` directory is generated output. Do not edit it directly; rebuild it after changing source files.

## Deploy to Netlify

The repository includes a `netlify.toml` file with the correct build settings:

- **Build command:** `npm run build`
- **Publish directory:** `dist`
- **Node.js:** 22 (from `.nvmrc`)

### Recommended: connect the GitHub repository

1. Push the project to GitHub.
2. In Netlify, choose **Add new project → Import an existing project**.
3. Select GitHub and choose `kiqout/alpiq-energy-map`.
4. Keep the repository root as the base directory.
5. Confirm the build command is `npm run build` and the publish directory is `dist`.
6. Deploy the site.

Netlify will install the dependencies from `package-lock.json`, run the build, and publish the generated `dist/` directory. Future pushes to the connected branch will trigger new deployments.

### Manual drag-and-drop deploy

Build the site on your computer first:

```bash
npm ci
npm run build
```

Then drag the **`dist` folder** into Netlify's manual deploy area. Do not upload the repository root: the root `index.html` references `assets/app.js` and `assets/app.css`, which are generated inside `dist/` by the build script.

## Switzerland 3D terrain assets

The Swiss terrain scene needs generated files under `public/terrain/`:

```text
public/terrain/
├── ch_satellite.jpg
├── ch_hillshade.png
├── ch_night_radiance.png
├── ch_mask.png
├── ch_height_u16.bin
├── ch_vectors.json
├── ch_scene.json
└── ch_municipality_lights.bin
```

These assets are generated from public geospatial sources. On Windows, run:

```text
BUILD_SWISS_3D_SCENE.bat
```

The script creates an isolated Python environment, installs the dependencies from `scripts/requirements-swiss-terrain.txt`, downloads/processes the source data, and generates the municipality-light layer.

**Important for GitHub and Netlify:** the current `.gitignore` excludes the generated files in `public/terrain/`. As a result, a fresh GitHub checkout does not contain the complete Swiss terrain dataset. If you want the Switzerland 3D scene to work on the deployed site, remove the corresponding `public/terrain/*` ignore rules (or force-add the generated files), commit the generated assets, and push them to GitHub. Netlify can then copy them into `dist/` during the normal build. The standard Netlify build does not run the Windows `.bat` terrain-generation script.

If the terrain assets are absent, the World and Europe globe and the rest of the dashboard can still load, but the dedicated Switzerland terrain view will show a missing-data message.

## Data and methodology

The displayed figures are based on publicly available Alpiq reports and other linked public datasets. Source links and methodology notes are also available inside the application.

A few important interpretation points:

- Production values represent Alpiq's reported share of power-plant production, not the total electricity output of the countries in which its assets operate.
- The 2026 selection is **H1 2026 interim data**. It is not annualized or presented as a full-year result.
- The lighting comparison is an estimate for building and outdoor lighting. It is not total electricity demand and does not imply that Alpiq physically supplies that region's lighting load.
- The global nighttime-lights texture is geographic context. It is not a map of Alpiq assets, ownership, or electricity deliveries.
- The gas-fleet comparison is a hypothetical emissions-intensity benchmark, not a measurement of emissions physically avoided.
- The tree equivalent is based on an illustrative annual CO₂-absorption assumption. It does not represent trees planted or verified carbon removals.
- Swiss motorway corridors and the 2,110 municipality-light positions are illustrative visual layers, not surveyed road geometry, power lines, or official municipality centroids.
- Published report tables may use different comparison bases or rounding. The application includes notes where these differences affect interpretation.
